# artwork

two original monochrome editorial images for helox terminal. generated with the built-in imagegen tool; these are decorative physical ribbon studies, not hardware photographs or measured input graphs.

- `helox-cover.png`: white movement ribbon sweeping from a fine line into a broad arc on matte charcoal, silver endpoint, lowercase monospace title.
- `motion-study.png`: two white physical ribbons on a dark machined slab, contrasting irregular and broad sweeping paths, silver anchors, no text.

both prompts requested wide 3:1 framing, restrained studio light, white/black/silver only and generous negative space. no third-party branding, neon, circuitry or fake interface elements. the final images are 2172 × 724 pixels. alt text and captions are supplied in the root readme.
